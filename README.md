Разработка интернет-приложений (РИП) 2025

Расчет стоимости за отопительный сезон

Разработанное приложение позволит покупателям создавать и формировать заявки на расчёты стоимости за отопительный сезон для выбранных ими теплонагревателей, а инженерам завершать или отклонять данные заявки.
